**Quick wins — top 5**

1. Remove duplicate initial loads on Members and Join Requests (#7).
2. Preserve avatar byte identity and set physical-pixel decode dimensions (#14).
3. Cache derived Quran portions instead of constructing every portion per lookup (#17).
4. Share one Mushaf initialization Future and retain Home’s initialization Futures (#5, #18).
5. Reuse cached reminder schedules and coalesce reminder refreshes (#3).

**Things NOT worth doing**

- **Repeating the completed Mushaf work:** font verification isolates/markers, settled directional prefetch, cached paragraph painting, idle layout preparation, reader rebuild filtering, debounced position saves, and bounded nearby page retention are already implemented.
- **Changing the renderer based on existing emulator results:** the performance document records software-GPU measurements and explicitly retains the platform default. Physical-device acceptance remains unverified.
- **Moving all SQLite access to another Dart isolate:** native sqflite already executes SQL on background threads. Target the demonstrated Dart JSON scans, result mapping, and excessive calls instead. [sqflite documentation](https://pub.dev/packages/sqflite).
- **Adding another isolate around every Supabase response:** the installed PostgREST implementation already uses Supabase’s JSON isolate for responses over its size threshold. Profile remaining model conversion before adding another processing layer.
- **“Enabling shrinking” as a new Android fix:** the installed Flutter Gradle plugin already enables release minification/resource shrinking by default: [FlutterPlugin.kt:209](C:/flutter/flutter/packages/flutter_tools/gradle/src/main/kotlin/FlutterPlugin.kt:209). iOS Release already uses optimized Swift compilation: [project.pbxproj:530](H:/quran_daily-wt/mushaf-perf/ios/Runner.xcodeproj/project.pbxproj:530).
- **Removing/subsetting Quran assets or required fonts:** the largest assets have active readers/fallback consumers. The source tree contains about **4.42 MiB of Quran assets** and **1.67 MiB of fonts**, not a large unused media collection. Preserve their bytes, integrity checks, and offline availability.
- **Blanket `const`, `buildWhen`, fixed row heights, or repaint-boundary sweeps:** prioritize measured hot paths. Fixed heights risk Arabic wrapping and 200% text scale; broad filters can hide meaningful state updates.
- **Introducing polling, Realtime, a new state-management system, or deferred feature delivery:** none addresses the concrete request waterfalls above. The existing Cubit/repository architecture can support these fixes with less complexity.
